# Austin Yates — Personal Portfolio Scaffold

A three-page semantic HTML portfolio starter.

## Files
- `index.html` — Home page
- `projects.html` — Projects / Work page
- `about.html` — About / Contact page
- `wireframe.png` — Site plan and visual direction

## Initial design direction
- **Primary:** navy blue `#1E3A8A`
- **Accent:** blue `#60A5FA`
- **Background:** very light blue-gray `#F1F5F9`
- **Text:** charcoal `#1F2937`
- **Muted:** slate gray `#6B7280`
- **Headings:** Poppins (or a similar sans-serif)
- **Body:** Inter (or a similar sans-serif)
